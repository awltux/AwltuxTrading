{# The deep-dive prompt dialog: the box the reader edits, and the two buttons that end it. They must ask the same question of the same endpoint, and two copies of this form is exactly how the header's copy would come to post to a different place or lose the prompt URL. `dialog_id` is a parameter rather than a constant because two elements cannot share an id, and the button that opens one names it (`data-dialog`, wired in `app.js`). The prompt box is matched by *class* for the same reason. The prompt is fetched when the dialog opens, not rendered with the page: building it reads the held annual reports to work out the scope, which measured 8.4 seconds for a company with two 10-Ks on file. #}
