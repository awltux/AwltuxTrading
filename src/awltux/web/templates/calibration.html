Calibration

This is what makes a decision auditable rather than merely recorded. Only actionable calls (BUY / STRONG BUY / SELL / REDUCE / AVOID) are scored — HOLD asserts no direction, so counting it either way would flatter or penalise the model for a claim it never made.
